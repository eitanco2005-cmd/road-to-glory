## 1. WhatsApp share on every free calculator

- **`docs/assets/share.js`**: a shared helper. Add a `<div data-share …>` box, then the script. It renders:
  - **"שתפו בוואטסאפ" / "Share on WhatsApp"**: a `wa.me/?text=` link with a short message (it can include the result, e.g. "…כדאי לשים בחתונה ₪550 (מגיע/ה לבד)") plus a link.
  - **A second button**: the native `navigator.share` sheet on touch devices, or "copy link" on desktop (clipboard, with an execCommand fallback).
- **How the link reopens the same calculation**: the link is `<page>#c&field=value&…`.
  - Only fields that differ from the page defaults go in. Allowed: numbers, selects, radios and checkboxes.
  - Never included: free text, email or phone fields, textareas, anything marked `data-share-skip`, and the tip jar.
  - On load the hash is applied and input/change events are fired, so each page's own calculator recomputes. No changes to calculator logic were needed.
  - The hash is captured before the calculators rewrite the URL, because some of them call `replaceState`, which drops the hash.
- **Wired on 13 calculators**:
  - Hebrew (9): wedding-gift, bar-mitzvah-cost, vat-calculator, osek-patur-ceiling, budget-503020, net-salary-budget, renovation-cost, savings-goal, sufganiyot-calculator.
  - English (4): bar-mitzvah-budget, bar-mitzvah-gift, seder-shopping-calculator, hanukkah/latke-calculator.
  - Script used: `tools/site/add_share.py` (idempotent).
- **Privacy decision**: the personal-finance calculators (salary budget, 50/30/20, osek patur, savings goal) use a generic message with no figures. They also show the note "הקישור כולל את המספרים שהזנתם – שלחו אותו רק למי שתרצו". The event calculators put the result in the message. No names anywhere.
- **Old share links removed**: the "העתיקו קישור" links on 503020, net-salary and savings-goal are replaced by the new bar, and their handlers are removed from `calc.js`.
- **Net-salary category rows**: only rows the user typed are shared. `calc.js` tags auto-filled rows with `data-share-skip`.
- **og:image (1200×630, Hebrew)** for the top 4 calculators: wedding-gift, bar-mitzvah-cost, vat-calculator and osek-patur-ceiling.
  - Files: `docs/assets/og/*.png`, generated by `tools/site/make_og.js` (Playwright + Assistant font).
  - Each page sets og:image with width/height plus twitter:image.
  - The example numbers on the cards match each calculator's real defaults.
- **CSS**: the WhatsApp button is green #167a41 (white text 5.4:1 contrast), and the bar is hidden in print.
- **New test `tools/site/e2e_share.js`** (149 checks). For each of the 13 calculators it:
  - changes inputs and checks the wa.me link holds the message plus the link;
  - opens the link in a fresh mobile context and checks the results are identical;
  - checks the copy fallback, that there is no overflow at 375px, and that there are no JS errors.
  - It also checks that free text from the VAT quote builder never reaches the link, and that defaults produce a plain URL.

### Decisions
1. **"jewish wedding checklist" already exists** (`en/guides/jewish-wedding-checklist/`, 1,600 words, paired with the Hebrew twin).
   - A second page for the same query would compete with it.
   - I used that slot for **"Jewish wedding processional order"**, which has strong US intent, does not overlap, links to the checklist, and comes with a printable line-up sheet.
2. **"bar mitzvah planning checklist" vs. the existing "planning timeline"**: the new page is the short printable tick-box version.
   - It has a different title and description, the two pages cross-link, and the new page says outright that the timeline explains the reasoning.
   - Some overlap risk remains; worth watching in Search Console.
3. **The EN generator (`products/en-jewish-life/site_en.py`) is stale** compared with the live pages: it would remove the Hanukkah banner on `en/` and the app-unlock code on `en/thanks/`. I did **not** run `main()`.
   - New content lives in `round2_pages.py`, which writes `guides/*.json` and `seating/*.json`, and is rendered through `guide_page()` (now able to handle the seating section, HowTo and related_app).
   - The 3 EN tool sources also carry the share bar, so a future regeneration keeps it.
   - Someone should fold the hand edits on home and thanks back into the generator before anyone runs `main()` again.
4. hreflang is set in the EN page `<head>` and in `docs/data/hreflang.json`, which now has 11 pairs and feeds the sitemap. The Hebrew twins get their reciprocal links through the sitemap only, the same as the existing pairs.
