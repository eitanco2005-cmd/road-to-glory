## Decisions
- **Placeholder JSONs.** All 6 products carry `"placeholder": true`, `files: []`. checkout.js only sells a product if it is not a placeholder **and** has files or a Sheets link. Otherwise it shows a disabled "בקרוב" button, so nobody can pay for a file that doesn't exist yet. Bundles are sellable only when every member product is. **When merging W2–W4, take their `docs/data/products/<slug>.json`** (add/add conflict): their files have no `placeholder` flag.
- The 4 bundle JSONs (`event-bundle` ₪69, `money-bundle` ₪59, `freelancer-bundle` ₪55, `everything-bundle` ₪129) belong to W1. The thanks page shows a bundle's files grouped by member product.
- `docs/data/products/index.json` holds `{categories, products:[{slug,category}], bundles:[slugs]}`. `docs/data/tools.json` lists the 6 tools (title, description, icon, linked product).
- Cards link to `p/<slug>/` and `tools/<slug>/` only if the page exists. JS checks with a HEAD request; `build_site.py` checks the file. Otherwise the card shows "בקרוב".
- Optional extra product JSON field `image` (path from docs root, e.g. `p/wedding-planner/screen-1.png`) becomes the card thumbnail. Without it, the card shows a category icon.
- All script URLs are derived from the script's own `src`, so the site works under `/road-to-glory/` or a custom domain. Pages use relative paths per the contract.
- Sales POSTs use `text/plain` (no CORS preflight). The redirect to the thanks page never waits more than 2.5 s for the log. A failed log is queued in localStorage and retried on the next page load. The endpoint de-duplicates by order id.
- Test sales (`TEST-…`) are logged with `test:true` and excluded from the money totals.
- The endpoint can optionally **verify every order with PayPal** (needs the Secret as an HF Space secret, never in the repo). That gives real fees and net, and flags fake POSTs.
- Free HF Spaces have ephemeral disk, so the endpoint can back its JSONL files up to a private HF dataset (`HF_TOKEN` + `HF_DATASET_REPO`).
- Seller-facing copy avoids promising a tax invoice ("PayPal sends a payment confirmation; documents per the law"). The owner is not yet an עוסק.

## Known limits
- Download links are visible in the public product JSONs, so anyone who reads the JSON can get the files without paying. The contract accepts this ("low prices make this a small loss"). Stronger protection would need a server: the endpoint could issue signed links after PayPal verification.
- `robots.txt` is ignored on a GitHub *project* site, because it has to be at the host root. Submit the sitemap in Search Console instead.
- I couldn't build the Docker image here (no Docker). `app.py` is covered by `test_app.py` and by the e2e test running it under uvicorn.
- PayPal button images didn't load in the headless sandbox (network), but the button iframes rendered. A real ₪1 purchase is still the manager's final check.
