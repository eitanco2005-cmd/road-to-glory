## Verification (`python3 etsy/validate.py` → ALL PASSED)
- Titles 124–140 chars; Etsy's "& : % only once" rule checked; 13 unique tags each ≤20 chars (letters/numbers/spaces).
- Files: 1–5 per listing, largest 1.7 MB (limit 20 MB). All xlsx (incl. inside ZIPs) recalculated in LibreOffice: **0 formula errors**. PDFs open and render (20 / 26 pages).
- **No site/PayPal links**: every xlsx XML part, PDF text layer and listing text scanned for netlify/tichnun./paypal/http(s) (schema URLs excepted). Site footers were stripped at the XML level (charts/styles untouched); Hanukkah PDFs re-printed with a link-free footer.
- 85 images, all exactly 3000×2250 JPEG; every file and photo referenced in its listing.md.

## Decisions
- **Etsy limits verified**: 5 files/listing, 20 MB each (Etsy Help Center "How to Manage Your Digital Listings"); ZIP counts as one file → bundles 10/11 ship as ZIPs.
- **Prices** set low to sell from a new, review-less shop: Etsy wedding budget spreadsheets seen at ~$3.66–$21.55 (many $5–17); Hanukkah printables elsewhere $3–$17. Bundles ~30% off the sum.
- **Wedding Budget Planner** built new and generic (not Jewish-specific) to reach the much larger "wedding budget" Etsy search; reuses the en-jewish-life xlsx style helpers. MINIFS avoided (Excel 2016 compatibility).
- **Seating chart**: new xlsx (Guests → Tables with over-capacity warnings → Seating Plan filled seat-by-seat via INDEX/MATCH keys, no dynamic arrays, works in Excel 2016/Sheets/LO) + printable kit (round 8/10/12, head table, floor plan, Find Your Seat A–Z, table numbers 1–30), Letter + A4.
- Hebrew products not listed (Etsy buyers are English-speaking); Purim planner skipped (Hebrew-only).
- Shop name "TichnunPlus" matches the "Tichnun Plus" name left inside the files (brand name is allowed; links are not).
- AI disclosure: every description has "WHO MADE IT: designed by our shop… created with the help of AI tools, then checked and tested by us"; guide tells the owner to answer Yes to any AI question. "Who made it" = I did.
- Category paths are given as "type X in the category box and pick …" because Etsy's taxonomy UI is a search box and exact paths vary; a fallback is given each time.
- No fake reviews, no claims of sales/bestseller.
