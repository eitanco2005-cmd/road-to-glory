# Upwork profile + Project Catalog — ready to paste

Limits (third-party sources, consistent with each other): profile title 70 chars,
overview 5,000 chars with only the first ~200 chars shown before "more"
([snipework][s1]). Project Catalog: title ~75 chars incl. "You will get…" prefix,
description 120–1,200 chars, 5 search tags ([snipework][s2]). The editor enforces the
real limits.

Strategy: a new profile wins few bids, and each proposal costs Connects. Rely on a
**Project Catalog** listing (buyers come to you) and send only a handful of highly
targeted proposals per week to jobs that say "landing page", "one page website",
"small business website", posted < 24h ago, with < 10 proposals.
