# 5 ready replies for buyer messages

Where: **Shop Manager → Messages**. Tip: save these once as "Saved replies" (in a message, click the "Saved replies" icon → "Create new"), then each reply is two clicks.
Replace [NAME] with the buyer's first name.

## 1. "Where is my file? / I can't find the download"
```
Hi [NAME], thank you for your order!
Your files are on Etsy right now: click your profile picture (You) > Purchases and reviews > find this order > "Download files".
If you're on the Etsy phone app and don't see the button, open etsy.com in your phone's browser or on a computer and follow the same steps.
If it still doesn't show, just reply here and I'll help.
```

## 2. "How do I open it in Google Sheets?"
```
Hi [NAME], happy to help!
1. Go to drive.google.com and sign in.
2. Click "New" > "File upload" and choose the .xlsx file you downloaded.
3. Double-click the file in Drive, then click "Open with Google Sheets" at the top.
Tip: in Sheets, choose File > "Save as Google Sheets" so all features work smoothly. Type only in the yellow cells; everything else calculates by itself.
```

## 3. "The file won't open / looks broken"
```
Hi [NAME], sorry about that! Let's fix it.
Could you tell me which file it is and which program you're using (Excel, Google Sheets, Numbers, phone or computer)? A screenshot helps too.
Most of the time, downloading it again from Purchases and reviews, or opening it in Google Sheets, solves it. If it doesn't, I'll send you a working file or a full refund, whatever you prefer.
```

## 4. "Can you customize it / add something?"
```
Hi [NAME], thanks for asking!
The spreadsheets are fully editable: you can rename categories, add rows and change any list item yourself. The yellow cells are yours to change.
I'm not offering custom versions right now, but if something important is missing, tell me what it is and I'll consider it for the next update (you'd get the update free).
```

## 5. "I'd like a refund"
```
Hi [NAME], I'm sorry it wasn't what you needed.
Could you tell me what went wrong? If the file doesn't work or isn't what the listing described, I'll refund you in full (within 14 days of purchase). If it's something I can fix, I'm also happy to send a corrected file.
```
(Refund how-to: Shop Manager → Orders & shipping → open the order → "Issue refund" → full refund.)
