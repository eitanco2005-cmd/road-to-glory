# Product research: Hebrew-first self-serve digital products

Worker R, 2026-11-17. Rules followed: no outreach, no promotion. Sales come in from Google search and free tools, then PayPal checkout, then an automatic download.

## How demand was measured (read this first)

I had no keyword-volume tool (Google Keyword Planner, Ahrefs and similar need accounts). So "demand" is inferred from three things:
- **SERP shape:** how many Israeli sites built pages for the query. Publishers only do that for queries with volume.
- **Paid competitors:** someone already charging ₪ for the thing proves people pay.
- **Media coverage:** recurring articles in mako, Walla, Israel Hayom and Kipa point to a seasonal, mass-market query.

"Weak competition" means the search found **no ready-made Hebrew paid product** for that exact need. Results came mostly from WPS, Microsoft or English-language sites, or from free articles with no file to download.
**Action for the owner/manager:** once the site is live, check real volumes in Google Search Console, and in Keyword Planner if an Ads account exists. Re-rank after 2 to 3 weeks of impressions data.

Prices for Israeli VAT and fees: PayPal Israel lists domestic digital-goods *micropayment* rates of 5.0% + fixed fee (5.9% incl. VAT). These rates need an application, and the standard rate is on the same page ([PayPal IL fees](https://www.paypal.com/il/webapps/mpp/merchant-fees)). The owner should confirm which rate applies to the account.

## 3. Ranking: top 6 to build first

1. **Wedding planner (#1) + "כמה לשים בחתונה" calculator.** Biggest gap. Buyers are in a high-spend, high-stress moment, so ₪49 is trivial next to a ₪100k+ event. The calculator query is mass-market and recurs every wedding season.
2. **Household budget Pro (#2) + 50/30/20 calculator.** The only category with a *proven paying Israeli market* (Financa sells at ₪99–120). We undercut at ₪39–49 and offer a modern Google Sheets version.
3. **Osek patur 2026 tracker (#3) + ceiling calculator.** Specific, dated query ("2026") with no product competitor. Buyers are freelancers who already pay for tools. It needs a refresh every January, and that refresh becomes a repeat sale.
4. **Bar/bat mitzvah planner (#4).** Almost free to build once #1 exists. Sells as a bundle upsell.
5. **Hebrew price-quote pack (#5) + VAT calculator.** Small, fast, evergreen B2B purchase. It also gets small businesses onto the site, and the osek patur tracker can be cross-sold to them.
6. **Renovation budget (#6).** Unserved Hebrew query with high stakes for the buyer. Financa's content shows the topic gets search interest.

Not first: CV pack (#7), psychometric (#8) and bagrut (#9). Free supply is saturated, or buyers can't pay easily. Salary calculator (#10): the field is crowded and the 2026 tax rules change mid-year, so it costs too much maintenance for now.

## 4. SEO basics for ranking Hebrew pages fast

**Markup / technical**
- `<html lang="he" dir="rtl">` on every page. Set direction in HTML, not only CSS. Use CSS logical properties (`margin-inline-start`) ([RTL best practices](https://skills.sh/skills-il/localization/hebrew-rtl-best-practices)).
- Hebrew-only site: no hreflang needed. If an English version is added, use `he` (not the old `iw`), keep the tags reciprocal, and add `x-default` ([Savvy](https://savvy.co.il/en/blog/wordpress-seo/hreflang-attribute-multilingual-website/), [SEJ](https://www.searchenginejournal.com/hreflang-multilingual-website/)).
- Use Hebrew slugs or clean transliterated slugs. Transliterated (`/wedding-planner-excel`) is easier to share and avoids `%D7…` URLs.
- Fast static pages (GitHub Pages is fine), mobile-first, self-hosted Hebrew webfont (Heebo/Assistant) with `font-display: swap`.
- Submit `sitemap.xml` in Google Search Console on day one and request indexing per page. This is the single biggest speed-up for a new domain.

**Titles & content**
- Title ≤ 60 chars, exact Hebrew query first: `כמה לשים בחתונה 2026 – מחשבון מעודכן | <brand>`. Meta description ~150 chars, written in natural Hebrew.
- One H1 that matches the query. Use H2s for the sub-questions people actually ask ("כמה לשים כזוג?", "כמה לשים לבן דוד?").
- Put the year in title and H1 for dated queries (2026 brackets, ceilings), and update every January.
- Add a short, genuinely useful answer above the fold, then the tool, then the explanation.
- Link internally: tool → product → related tool.
- Write the Hebrew by hand. Avoid machine-translated phrasing. Use both spellings where common (צ'ק/שיק, אקסל/Excel).

**Schema (JSON-LD)**
- `Product` + `Offer` (`priceCurrency: "ILS"`, `price`, `availability`) on product pages. `WebApplication` or `SoftwareApplication` (free, `price: 0`) on tool pages. `BreadcrumbList` on all pages. `Organization` on the home page.
- `FAQPage` no longer produces FAQ rich results (Google finished that phase-out in May 2026). It is still harmless and helps Google understand Q&A, but don't expect rich results from it. `HowTo` rich results were removed in 2023 ([TechWyse](https://www.techwyse.com/news/ai-search/google-faq-rich-results-deprecated-2026), [SER](https://seroundtable.com/google-drops-how-to-rich-results-desktop-search-36046.html)). This is from secondary sources, so verify on Google Search Central before relying on it.
- Never add fake `aggregateRating`/reviews. That would break the project's honesty rules and Google's policy.
