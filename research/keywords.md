# Keyword map (Hebrew), P2 SEO worker, 2026-11-17

## How these phrases were collected (read first)
- **Google autocomplete could not be queried directly.** The suggest endpoint (`suggestqueries.google.com`) is blocked by this environment's network proxy (HTTP 403).
- Instead, each phrase was checked with a live web search (Nov 2026). A phrase is listed only if at least one of these is true:
  - Israeli sites built a page with that exact wording in the title or URL (for example financa, moneyplan, hasolidit, mako, walla, kolzchut, greeninvoice, bizportal).
  - It appeared as a recurring question in those pages' FAQ / "people also ask"-style headings.
- **No search volumes.** The order within each intent group is our best guess at size, based on how many publishers target the phrase.
- **Action:** after 2–3 weeks of Google Search Console impressions, re-rank this list by real data and rewrite titles to match the winning queries.

Intent labels:
- **I** = informational (guide)
- **T** = wants a tool or calculator
- **C** = commercial (wants a file or template to download, possibly paid)

"Our page" is the page that targets the phrase. Pages marked *new* were added in this P2 work.
