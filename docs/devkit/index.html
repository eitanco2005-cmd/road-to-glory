How it works

No left, no right, no second stylesheet.

Logical properties

.card { padding-inline: 1.5rem; /* not left/right */ border-inline-start: 4px solid; /* right in RTL, left in LTR */ text-align: start; } .badge { inset-inline-end: 1rem; }

Bidi-safe data

<p>המחיר: <bdi>₪1,250</bdi> לחודש</p> <input type="email" dir="ltr"> /* aligned to end */ <svg class="flip">…arrow…</svg> :lang(ar) body { font-family: "Noto Kufi Arabic"; }

One markup, three languages

עברית, العربية and English from the same file, with fonts and line height per language.

Plain CSS or Tailwind

17 KB of readable CSS, or Tailwind 3.4 with logical utilities: ms-, ps-, start-, text-start.

Accessible & fast

Skip link, labelled forms, focus styles, dark mode, reduced motion. No images required: mockups are pure CSS.

FAQ

Is the free kit really free for commercial work?

Yes. MIT license: use it for clients and products, no attribution required.

Do I need Tailwind?

No. Every template works with one plain CSS file. The Tailwind variant is there if your stack already uses Tailwind 3.4+.

Does it work for Persian or Urdu?

The layout does (any RTL language). Add your font in the --font-* variables and a :lang() rule.

Are the Pro templates in Arabic too?

They ship with Hebrew placeholder text and Arabic typography built in: set lang="ar" and replace the text. The free templates include full Arabic copy and a language switcher you can reuse.

Which browsers?

Current Chrome, Edge, Firefox and Safari.

How do I get the Pro files after paying?

You're taken straight to a download page. Bookmark it: the link keeps working for updates.
