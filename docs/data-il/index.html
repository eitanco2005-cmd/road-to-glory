שימוש בקוד

JavaScript (דפדפן או Node, בלי תלויות):

<script src="https://tichnun.netlify.app/data-il/israel-data.js"></script>
<script>
  IsraelData.isIsraeliHoliday("2026-04-22");  // [{id:"yom-haatzmaut", name_he:"יום העצמאות", ...}]
  IsraelData.isRestDay("2026-09-21");         // true (Yom Kippur)
  IsraelData.addVat(1000);                    // {net:1000, vat:180, gross:1180, rate:0.18}
  IsraelData.removeVat(1180);                 // {net:1000, vat:180, gross:1180, rate:0.18}
  IsraelData.osekPaturCeiling(2026);          // 122833
</script>

שאלות נפוצות

מה הרישיון?

הנתונים משוחררים לנחלת הכלל (CC0 1.0) והקוד ברישיון MIT. מותר להשתמש בהם בכל מקום, גם מסחרי, בלי לבקש רשות. קרדיט עם קישור יתקבל בברכה.

איך חושבו תאריכי החגים?

בחישוב אריתמטי של הלוח העברי (Dershowitz & Reingold), עם כללי הדחייה הנהוגים בישראל: יום טוב אחד, פסח של 7 ימים, הקדמת ודחיית יום הזיכרון ויום העצמאות, יום השואה וצומות שחלים בשבת. כל 144 התאריכים הושוו לשתי ספריות עצמאיות (hdate, pyluach) בלי אף אי-התאמה.

מתי חג מתחיל?

שדה start הוא היום הראשון (באור יום). חגים עם begins=sunset_previous_day נכנסים בשקיעה של הערב הקודם (שדה eve). צומות קלים (גדליה, עשרה בטבת, אסתר, י״ז בתמוז) מתחילים בעלות השחר.

איך מעדכנים?

הנתונים נבדקים מול המקורות המצוינים בכל שורה. מצאתם טעות? פתחו issue במאגר ב-GitHub.

Israeli open data (English)

A small, carefully sourced dataset for developers and journalists: Israeli holiday dates 2025–2030 with Hebrew and English names (computed with the arithmetic Hebrew calendar, Israeli rules, cross-checked against two independent libraries), plus VAT rate history, the osek patur (exempt dealer) turnover ceiling, minimum wage and Bituach Leumi basics, each value with a source URL and a check date. Data is CC0 (public domain), code is MIT. Downloads are in the table above (JSON + CSV), the zero-dependency JavaScript helper is israel-data.js and the Python package installs straight from GitHub:

pip install "git+https://github.com/eitanco2005-cmd/road-to-glory.git#subdirectory=data-il/python"
npm: not published; use the CDN or copy the file:
<script src="https://cdn.jsdelivr.net/gh/eitanco2005-cmd/road-to-glory@main/data-il/js/israel-data.js"></script>
