בלי שולחן (0)

גוררים שם לשולחן (בטלפון: לחיצה ארוכה ואז גרירה), או לוחצים על שם כדי לערוך, לבחור שולחן ולסמן "לא להושיב יחד".

מה חינם ומה בתשלום?

חינם, בלי הגבלה: כל הכלי על המסך, כמה מוזמנים ושולחנות שתרצו, הושבה אוטומטית, התנגשויות, ייבוא מאקסל, גיבוי, והדפסה / PDF עם סימן מים.

גרסה מלאה, ₪29 חד-פעמי: PDF נקי (מפת שולחנות + רשימת כניסה לפי א-ב), ייצוא לאקסל, וכרטיסי שולחן להדפסה. נפתח מיד אחרי התשלום, בלי הרשמה.

פרטיות

הרשימה לא נשלחת אלינו ולא לאף אחד: היא נשמרת רק בדפדפן במכשיר הזה. כדי להעביר למחשב אחר או לשמור עותק, השתמשו ב"שמירת גיבוי" בתפריט ⋯.

מתכננים את כל החתונה? מתכנן החתונה באקסל מחבר תקציב, ספקים, אישורי הגעה ומתנות. ויש מדריך לסידורי הושבה ומחשבון כמה שולחנות צריך.
