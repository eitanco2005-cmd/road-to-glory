שאלות נפוצות

כמה מדויק המחשבון?

זה אומדן ראשוני בלבד, לפי טווחי מחירים שפורסמו באתרי מחירונים ישראליים ב-2026 (המקורות למטה). המחיר האמיתי תלוי במצב הדירה, בחומרים, באזור ובקבלן. השתמשו בו כדי לדעת סדר גודל, ובקשו לפחות 3 הצעות מחיר כתובות.

האם המחירים כוללים מע"מ?

המקורות לא תמיד מציינים זאת במפורש. כשמשווים הצעות, ודאו שכולן באותו בסיס: מחיר + 18% מע"מ.

למה להוסיף בלת"מ?

כמעט בכל שיפוץ מתגלים דברים אחרי שפותחים קירות ורצפות, כמו צנרת ישנה, רטיבות או חשמל שלא עומד בתקן. מקובל לשמור 10%–20% מהתקציב בצד, ובבית ישן כדאי יותר.

מה לא כלול באומדן?

דלתות, חלונות ואלומיניום, נגרות וארונות, גופי תאורה, ריהוט, תכנון ופיקוח, היתרים, דיור חלופי והובלה. אפשר להוסיף אותם בשדה «עבודות נוספות».

הנתונים שלי נשמרים?
