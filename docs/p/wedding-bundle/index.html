הכלים רצים בדפדפן והנתונים נשמרים במכשיר שלכם. כדי לעבור מכשיר משתמשים בקובץ הגיבוי, ופותחים שם את הקישור לדף האישור כדי לפתוח את הגרסה המלאה.
